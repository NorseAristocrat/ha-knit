# Motion-controlled devices

For something that should go off when the room empties but must never be switched on for you: a
fan, a decorative light, a TV. It takes the same sensors as a light, either way round: a fan
that goes off a few minutes after the bathroom door opens. It gets the same countdown and card, and can be told to switch
off again if it comes back on by itself after a power cut.

Add one from Add integration → Knit → **Motion-controlled device**. Pick the device (a switch, a
light, a fan or a helper) and the sensors that keep it on. *Off again if it comes back on after a
power cut* is under Advanced options.
